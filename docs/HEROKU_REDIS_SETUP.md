## Environment Variables Explained

### REDIS_URL (Most Important)
```
redis://:password@hostname:port
```
- **Format:** `redis://[:password]@host:port[/db]`
- **Used by:** Bull queues, caching, session storage
- **Example:** `redis://:d8f3a2e1@ec2-18-220-1-123.compute-1.amazonaws.com:16379`

### REDIS_HOST
```
ec2-18-220-1-123.compute-1.amazonaws.com
```
- Hostname of the Redis server
- Uses AWS EC2 instance in Heroku region

### REDIS_PORT
```
16379 (Heroku default, not 6379)
```
- Heroku Redis uses non-standard port
- Helps prevent port conflicts

### REDIS_PASSWORD
```
d8f3a2e1 (example)
```
- Authentication password
- Automatically generated by Heroku
- Included in REDIS_URL

## Application Configuration

### Your App is Already Set Up For Redis

**File:** `src/defendxplus/defendxplus.module.ts`

```typescript
import { Module } from '@nestjs/common';
import { BullModule } from '@nestjs/bull';

@Module({
  imports: [
    BullModule.forRoot({
      redis: process.env.REDIS_URL || 'redis://localhost:6379'
    }),
    // ... queues and other modules
  ]
})
export class DefendxplusModule {}
```

### How It Works
1. On startup, NestJS reads `process.env.REDIS_URL`
2. Once Heroku Redis is available, the env var gets the Heroku connection string
3. Bull queues automatically connect to Heroku Redis
4. All scheduling, polling, and recovery use Heroku Redis

**No code changes needed!** ✅

## Troubleshooting

### If Addon Creation Fails
```bash
# Check status
heroku addons --app morning-peak-22250

# If stuck, you can destroy and recreate
heroku addons:destroy redis-rigid-59473 --app morning-peak-22250
heroku addons:create heroku-redis:premium-0 --app morning-peak-22250
```

### If Connection Times Out
- Ensure app is in same region (check: `heroku apps:info`)
- Check IP whitelist if using legacy Redis
- Verify DATABASE_URL works (other services need it too)

### If REDIS_URL is Empty
- Wait for provisioning to complete (can take 5+ minutes)
- Run: `heroku config:get REDIS_URL --app morning-peak-22250`
- If still empty, restart app: `heroku restart --app morning-peak-22250`
